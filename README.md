# Resume.md

A browser-based Markdown resume builder with live preview and ATS-friendly PDF export. It runs entirely in the browser, stores drafts locally, and requires no account.

[Open the live app](https://404jul.github.io/markdown-resume-builder/)

## Features

- Live Markdown editing and resume preview
- Multiple resume themes and layouts
- Markdown import and download
- Client-side PDF export
- Local browser storage

## Development

```sh
npm install
npm run dev
```

Run `npm test` for tests and `npm run build` to create the production build in `dist/`.

Built with React, Vite, Tailwind CSS, and daisyUI.
